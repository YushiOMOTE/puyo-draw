How to use

Hold a cell, then flick toward an option to place it.

⌫
  • Flick toward a colored circle to place that color.
  • Flick toward the gray circle to place garbage.
  • Release without flicking to delete the cell.

Sidebar controls

  • 0 Chain count: shows the current chain total.
  • Undo: goes back one board change.
  • Redo: restores an undone board change.
  • ▶ Simulate: starts the chain animation.
  • Reset: returns to the initial empty board.
